使用说明

请在 IDE 中运行；网页保存方案、查看产物并固定提交。

项目

个人项目按来源分组。归档只隐藏项目，磁盘文件保留；删除本地副本需确认后才删除项目目录及其中产物。教师任务在本页下方。

导入会创建新目录，不执行包内代码。重试不会覆盖已登记项目的编辑；只有原始字节完整的已知教师包可认证来源，旧 CLI 包或未知包不会认证为教师任务。

教师任务与资源包

教师任务

教师提供的资源自动可用。含案例的任务可点“开始任务”创建个人副本；同一版本重复点击只打开已有项目。

我的任务与资源包

算法配置与编排

从“我的项目”选择一个项目开始编排。

我的固定提交

这里只显示你的个人项目。每个版本均为提交时磁盘文件的不可变副本；日期按北京时间。

数据资源

显示本人数据和已获授权的平台数据。个人私有或审核可读数据不等于平台公共数据；加入项目只保存引用，不复制原始数据。

加入已有项目

选择项目后查看它已有的数据集引用。

勾选下方数据集后加入项目。

每次选择的是一个已登记的准确数据集版本或子集，不必逐个选择文件。IDE 运行、固定提交与审核都会使用这里保存的标准数据引用。

将项目文件保留为派生数据

只可选择当前项目目录中的普通文件。系统在服务器内逐块导入托管派生数据区；不会读取你的其他 home 文件，也不会覆盖原文件。

案例管理
案例管理只显示已入库的平台资源；每个版本可单独管理授权或删除。


算法库
展示当前账号可用的算法及不同版本。资源自动可用，可按需加入自己的项目（可指定步骤别名）；也可在此创建个人本地算法。
个人本地算法
创建的本地算法保存在个人工作区，可直接加入已有项目；提交固定版本时由管理员审核决定是否纳入平台算法库。
代码默认留空。填写算法名称等信息后创建基本接口骨架，加入项目后在 IDE 中编写实现；不预填教学代码。


资源分发
可分发含案例的完整任务，也可只发送算法和数据资源包。额外材料不会修改案例代码、已有算法配置或原有数据引用。

已布置任务


共享权限
撤销只影响未来的 Web 读取或复制，已保存的项目副本不会删除。系统教学样例原本公开；私密库仍受管理员文件权限约束，页面不会向外部发送目录内容。


已下架资产
下架资产不会出现在新的选择列表中。打开记录可查看引用并恢复；原文件、授权和历史记录仍保留。


回收站
仅回收站中的资产可预览永久清理。系统不会顺带删除个人项目、固定提交或历史记录；如有关联，会列出阻挡原因和建议处理顺序。
