# 水声 TDOA 定位实验

标签：`水声`、`被动定位`、`TDOA`、`参数对比`、`合成验证`

## 平台入库元数据（可直接复制）

- 案例标签：`水声`、`被动定位`、`TDOA`、`参数对比`
- 案例说明：基于五水听器 TDOA 的依赖零定位案例；比较匹配声速和失配声速对定位轨迹与误差的影响。
- 算法标签：`水声`、`TDOA`、`定位`、`线性解算`
- 算法说明：将相对到达时差乘以指定声速，构造线性定位方程，输出轨迹、误差和摘要。真值只用于评估，不参与解算。

以上文字供教师在审核入库表单中复制；案例文件不会自动写入网页元数据。

本案例使用无测量噪声的合成教学数据，基线近零误差仅说明公式匹配，不代表真实海洋定位精度。它使用五个水听器和十个合成声源时刻差，估计二维/三维位置中的 `x, y, z`。真值文件只用于计算误差，**不参与定位解算**。样例的生成声速固定为 1500 m/s；两个方案只改变定位时使用的声速，因此可直接比较声速失配带来的轨迹误差。

`sample-data/` 是可立即运行的只读目录数据。运行 `python generate_sample_data.py` 能从固定随机种子 2026 重建同一份目录数据和 `sample-data.zip` 单文件包。平台派生数据使用 ZIP 时，选择 `data_source: dataset`、`data_format: zip`，框架从数据集的 `data.bin` 直接读取 ZIP，不解压到项目目录。

目录数据集模式读取 `data_root` 下的 `hydrophones.csv`、`tdoa_measurements.csv` 与 `true_trajectory.csv`；ZIP 模式在包根目录读取同名文件。`data_root` 是显式路径前缀，平台原始数据集需要按其实际树结构填写，绝不隐式查找服务器目录。
