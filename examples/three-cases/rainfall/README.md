# 降雨倍率实验

标签：`教学演示`、`CSV`、`参数对比`、`可复现示例`

## 平台入库元数据（可直接复制）

- 案例标签：`教学演示`、`降雨`、`CSV`、`参数对比`
- 案例说明：以三条合成降雨记录演示本地或受控数据读取、倍率参数方案、每方案最新成功产物和结果对比。
- 算法标签：`降雨`、`倍率处理`、`CSV`、`教学演示`
- 算法说明：按参数倍率处理降雨记录，输出处理表、摘要和可视化；不修改原始数据。

以上文字供教师在审核入库表单中复制；案例文件不会自动写入网页元数据。

这是一个可立即运行的最小案例。默认从 `sample-data/rainfall.csv` 读取三条合成记录（总和为 10），并由 `scale` 算法按实验方案的倍率生成逐行处理表、摘要和 SVG 图。

默认使用本地只读样例数据。若改为平台已授权数据集，将 `project.yaml` 或实验方案中的 `data_source` 改为 `dataset`，填写 `dataset_id`；目录数据集的 `data_root` 是数据集内包含 `rainfall.csv` 的相对目录，ZIP 数据集使用 `data_format: zip` 并从 `data.bin` 读取。

运行入口由案例包附带的统一入口 `run_experiment.py` 提供：`python run_experiment.py --list` 查看方案，`python run_experiment.py --scheme factor-2` 运行。运行时先写独立批次，成功后由公共入口整理为每方案最新一套结果；失败保留旧成功及最近错误、参数；本案例不会自行创建全局 `results` 根目录。
